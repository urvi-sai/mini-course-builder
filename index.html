What you'll learn

Programs often need to make choices: show one message to some users and a different one to others, or pay a bonus only when sales are high enough. In this course you'll learn how a program written in the C programming language makes those choices.

By the end, you should be able to:

  • Use C's selection statements (if, if…else, if…else if and nested if…else) to let a program decide what to do.
  • Write the test inside an if statement using equality and relational operators: symbols that compare two values, such as "is equal to" or "is less than".
  • Work out the order in which C checks a test that uses several operators, using the rules of precedence and associativity.

Key term: selection structure. A piece of code that picks which instructions to run, depending on whether something is true or false.

Check-in: What does a selection structure do?

The answer is: it picks which instructions to run. Running instructions several times is repetition, and running them in order is sequence.

Control structures

A control structure sets the order in which a program's instructions run. It may sound surprising, but researchers have shown that every program can be built from just three of them:

  • Sequence: run instructions one after another.
  • Selection: choose which instructions to run.
  • Repetition: run the same instructions several times.

Sequence is the simplest, and it's what happens unless you say otherwise: the computer runs your C statements one after the other, in the order you wrote them. The comments on the right of this example show that order. 

#include <stdio.h>

int main(void)
{
    int a, b, c;                                // Order of execution

    a = 2;                                      // 1st
    b = 3;                                      // 2nd
    c = a + b;                                  // 3rd

    printf("Value of variable c is %d\n", c);   // 4th, value of variable c is 5

    a = 3;                                      // 5th

    printf("Value of variable c is %d\n", c);   // 6th, value of variable c is still 5

    return (0);
}

Notice that c is still 5 at the end, even though a changed to 3. The sum was worked out once, at step 3, and C doesn't go back and redo it. Each line runs once, top to bottom.

The rest of this course is about the second structure: selection.

The answer is 5. c was worked out once, at step 3, when a was still 2. Changing a to 3 later doesn't go back and change c.

Three kinds of selection

Selection lets a program take different paths depending on a condition. C gives you three kinds, based on how many paths there are to choose from:

  • Single selection: do one thing, or skip it. In C this is the if statement.
  • Double selection: pick one of two things to do. This is the if…else statement.
  • Multiple selection: pick one of many things to do. You can write this as a nested if…else or as an if…else if.

The next few lessons look at each one in turn.

Check-in: A program must choose one of four possible bonus amounts. Which kind of selection does it need?

The answer is multiple selection. Single selection is for "do it or skip it", double selection is for two choices, and anything more than two needs multiple selection.

Single selection: if

The if statement checks a condition. If the condition is true, the program carries out an action. If it's false, the program skips that action and moves on.

This program asks for your age and prints a message only if you're under 21: 

#include <stdio.h>

int main(void)
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if (age < 21)
    {
        printf("You cannot vote yet\n");
    }

    return (0);
}

The condition goes in round brackets after if: (age < 21). The action goes between the curly braces { }. If you type 17, you'll see "You cannot vote yet". If you type 25, the program prints nothing and simply ends.

Check-in: In the example program, what is printed if you type 25?

The answer is nothing. 25 < 21 is false, so the program skips the body of the if, and there's no else to run instead.

Double selection: if…else

An if…else statement chooses between two actions. If the condition is true, the first action runs. If it's false, the action after else runs instead. Exactly one of the two always happens, never both and never neither. 

#include <stdio.h>

int main(void)
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if (age < 21)
    {
        printf("You cannot vote yet\n");
    }
    else
    {
        printf("You have reached the legal age for voting\n");
    }

    return (0);
}

This is the same program as before, with an else part added. Now someone who types 25 also gets a message: "You have reached the legal age for voting".

Check-in: In an if…else statement, how many of the two actions run?

The answer is exactly one. If the condition is true, the if part runs. Otherwise the else part runs. Never both, and never neither.

Multiple selection: nested if…else

When there are more than two possible outcomes, you can put one if…else inside the else part of another. Putting one statement inside another like this is called nesting.

This program works out a sales bonus with four possible results:

#include <stdio.h>

int main(void)
{
    int sales;

    printf("Enter your sales amount: ");
    scanf("%d", &sales);

    if (sales > 50000)
    {
        printf("You earn a bonus of 1500\n");
    }
    else
    {
        if (sales > 35000)
        {
            printf("You earn a bonus of 500\n");
        }
        else
        {
            if (sales > 10000)
            {
                printf("You earn a bonus of 100\n");
            }
            else
            {
                printf("You are not entitled to any bonus\n");
            }
        }
    }

    return (0);
}

Read it from the top. Each else holds the next decision, one layer deeper. The program stops at the first condition that's true. For a sales amount of 40000, the first test (sales > 50000) is false, so it moves into the else. The next test (sales > 35000) is true, so it prints "You earn a bonus of 500" and skips everything else.

Check-in: Someone enters a sales amount of 20000. Which message do they see?

The answer is a bonus of 100. 20000 is not more than 50000 or 35000, so those tests are false. It is more than 10000, so that test is the first one that's true.

Multiple selection: if…else if

The nested version in the last lesson works, but each new choice pushes the code further to the right. You can often write the same logic as an if…else if chain instead: 

#include <stdio.h>

int main(void)
{
    int sales;

    printf("Enter your sales amount: ");
    scanf("%d", &sales);

    if (sales > 50000)
    {
        printf("You earn a bonus of 1500\n");
    }
    else if (sales > 35000)
    {
        printf("You earn a bonus of 500\n");
    }
    else if (sales > 10000)
    {
        printf("You earn a bonus of 100\n");
    }
    else
    {
        printf("You are not entitled to any bonus\n");
    }

    return (0);
}

The two versions do exactly the same thing. They check the conditions in the same order, and the first true one wins. Most programmers prefer if…else if because it avoids deep indentation (the spaces at the start of each line). That makes the code flatter and easier to read.

Check-in: How does the if…else if version compare with the nested if…else version?

The answer is same results, but easier to read. Both versions check the conditions in the same order and stop at the first true one. The chain just avoids deep indentation.

How a condition decides

Every if statement makes its decision based on its condition: the test in round brackets. You can think of the condition as a yes-or-no question.

  • If the answer is yes (the condition is true), the statements in the body of the if run. The body is the code between its curly braces.
  • If the answer is no (the condition is false), the body is skipped. If there's an else, its body runs instead.

The comments in this example show which path is taken, and when:

#include <stdio.h>

int main(void)
{
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    if (age < 21)                              // if (age < 21) evaluates to true
    {
        printf("You cannot vote yet\n");       // this statement in the if body will be executed
    }
    else                                       // if (age < 21) evaluates to false
    {
        printf("You have reached the legal age for voting\n");   // this statement will be executed
    }

    return (0);
}
Check-in: An if statement's condition is false, and there is no else. What happens?

The answer is: the body is skipped and the program carries on. A false condition simply means "don't run this part". It's not an error.

Equality and relational operators

Conditions are usually built by comparing two values. C has six comparison symbols. Equality operators check whether two values are the same or different. Relational operators check which value is bigger or smaller.

Most look like the maths symbols you already know. A few are typed differently, because keyboards don't have keys for ≠, ≥ or ≤:

In maths In C Meaning
===Equal to
≠!=Not equal to
>>Greater than
<<Less than
≥>=Greater than or equal to
≤<=Less than or equal to

Watch out for "equal to": it's written with two equals signs, ==. A single = means something else in C: it stores a value in a variable, as in a = 2;.

Check-in: Which condition checks whether x is equal to 10?

The answer is x == 10. A single = stores 10 in x instead of comparing, and => isn't a C operator at all. ("Greater than or equal to" is >=.)

Precedence and associativity

When a condition contains several operators, C needs to know which one to work out first. Two rules decide this:

  • Precedence is which operator goes first. It's like the maths rule that you multiply before you add.
  • Associativity decides between operators that have the same precedence: whether to work through them from left to right or from right to left.

The table covers the arithmetic, relational and equality operators you've met so far. The higher a row is, the earlier its operators are worked out.

Operators (highest precedence first) Associativity
( )Left to right
* / %Left to right
+ -Left to right
< <= > >=Left to right
== !=Left to right
=Right to left

Let's work through (8 - 5) > 3 != 6 step by step. One thing to know first: in C, a comparison that's true gives the number 1, and one that's false gives 0.

  1. Brackets come first. (8 - 5) is 3, which leaves 3 > 3 != 6.
  2. > has higher precedence than !=, so it goes next. 3 is not greater than 3, so 3 > 3 is false and becomes 0. That leaves 0 != 6.
  3. 0 really is not equal to 6, so 0 != 6 is true and gives 1.

The final result is 1, which means true.

The answer is 1, which means true. + has higher precedence than >, so C works out 2 + 3 first to get 5. Then 5 > 4 is true, which gives 1.

The cast operator

Every value in C has a data type: the kind of value it is. For example, int holds whole numbers like 13, and float holds numbers with decimals like 13.45. Sometimes you need to change a value from one type to another. This is called a type conversion.

There are two ways this can happen:

  • Implicitly: the compiler (the tool that turns your C code into a program) converts the value for you, automatically.
  • Explicitly: you ask for the conversion yourself using the cast operator. You write the type you want in round brackets in front of the value: (type_name) expression.

It's good practice to use a cast whenever you need a conversion. That way, anyone reading your code can see the conversion is deliberate. 

#include <stdio.h>

int main(void)
{
    int approx_dimension;
    float exact_dimension = 13.45;

    approx_dimension = (int) exact_dimension;

    printf("Approximate dimension:%d\n", approx_dimension);
    printf("Exact dimension: %0.2f\n", exact_dimension);
    return 0;
}

Here, (int) exact_dimension turns 13.45 into the whole number 13. The program prints "Approximate dimension:13" and then "Exact dimension: 13.45". Note that casting to int drops the decimal part instead of rounding, so even 13.99 would become 13.

The answer is 7. Casting to int drops the decimal part. It doesn't round up, so 7.9 becomes 7, not 8.

Quiz

Eight questions covering the whole course. After each one you'll see whether you got it right, and your score appears once you've answered all eight. Nothing is saved.

Question 1: Which of these is not one of the three control structures?

The answer is compilation. Every program can be built from sequence, selection and repetition. Compiling is how C code is turned into a program, not a way of ordering instructions.

Question 2: What does this code print? 
int score = 75;

if (score >= 50)
{
    printf("Pass\n");
}
else
{
    printf("Fail\n");
}

The answer is Pass. 75 >= 50 is true, so the if body runs and the else body is skipped. An if…else always runs exactly one of its two parts.

The answer is !=. Keyboards have no ≠ key, so C uses an exclamation mark followed by an equals sign.

Question 4: In the sales bonus program, someone enters exactly 35000. Which message do they see?

The answer is a bonus of 100. The test is sales > 35000, and 35000 is not greater than 35000, so that test is false. The next test, sales > 10000, is true.

Question 5: The variable age holds 21. Which condition is true?

The answer is age >= 21: 21 is "greater than or equal to" 21 because it is equal. The other three are all false when age is exactly 21.

The answer is 1 (true). * goes first: 2 * 3 is 6. Then -: 10 - 6 is 4. Last comes >: 4 > 3 is true, which gives 1.

Question 7: In 4 + 6 / 2 == 7, which operator does C work out first?

The answer is /. Division has higher precedence than addition, and both come before ==. So C works out 6 / 2 = 3, then 4 + 3 = 7, then 7 == 7, which is true.

Question 8: Which line correctly converts the float variable price to an int?

The answer is (int) price. A cast puts the type you want in round brackets in front of the value: (type_name) expression.
